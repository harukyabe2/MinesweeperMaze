# ルール説明<br>
盤面上にある鍵を取ってゴールする<br>
プレイヤーは上下左右の4方向に進むことができ，開けられるマスはプレイヤーが行くことができるかつその周囲8マスである．
<br>

# 操作説明<br>
タイトル画面：<br>
**1・2・3キー**で難易度（Easy/Normal/Hard）を選択してゲーム開始<br>
ゲームプレイ：<br>
**左クリック**で指定したマスへ移動するまたはマスを開ける<br>
**右クリック**で旗を立てる・取り消す<br>
リザルト画面：<br>
**C**キーで同じ難易度でリトライ，**B**キーでタイトル画面に戻る，**Esc**キーでゲームをやめる
<br>

# 作品のコンセプト<br>
マインスイーパーの論理パズルに迷路探索を融合させたゲームです．マスを開けたときに出る数字を頼りに地雷を避けながら，鍵を拾いゴールへ到達することが目的です．<br>
通常のマインスイーパーのすべてのマスを開けるとクリアというルールとは異なり，いかに少ない手数かつ地雷を避けて進めるかを評価するスコアシステムもあります．
<br>

# 設計と機能説明<br>
**技術的なアピールポイント**<br>
・幅優先探索（BFS）の活用<br>
スタートから鍵/鍵からゴールへの経路保証やプレイヤーの移動にBFSを使用しました．クリックしたマスに対し，まだ開いていないマスや地雷のマスを避けた最短経路を計算して移動する操作性を実現しました．<br>
・キャラクターのアニメーション<br>
経路の移動中には歩行，地雷を開けた場合にはダメージのアニメーションを追加してただ開けるだけの作業にならないように工夫しました．<br>
・オブジェクト指向設計<br>
難易度の設定やギミック追加がしやすくなるようにし，拡張性を持たせました．今後の拡張性としてスコアを稼げるアイテムを追加することや壊せないブロックの導入が挙げられます．
<br>

**クラス説明**<br>

**Titleクラス**<br>
タイトル画面の描画と入力処理を担当する．プレイヤーの選択に応じた難易度データを構築し，ゲームシーンへ受け渡す．
<br>
**Gameクラス**<br>
ゲーム全体の心臓部であり，オブジェクトの初期化，入力処理，更新処理，描画を統括する．時間計測やスコア計算などゲーム全体の進行状態も管理する．
<br>
**Cellクラス**<br>
各マスの状態（開閉，地雷の有無，旗，隣接地雷数）を保持し，描画の管理を行う．
<br>
**Boardクラス**<br>
2次元配列によってマス目の状態を管理する．動的な盤面の生成，BFSによる経路探索，周囲の地雷数の計算など，盤面に関するロジックを提供する．
<br>
**Playerクラス**<br>
キャラクターの座標やアニメーション，ダメージ処理を管理する．Gameクラスを介してBoardクラスから得た経路情報をもとに，移動処理を行う．
<br>
