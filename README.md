# マインスイーパー迷路<br>

## ブラウザゲーム<br>
<a href="https://harukyabe2.github.io/MinesweeperMaze/" target="_blank">ゲームをプレイ</a><br>
* PCブラウザ（Chrome等）からアクセスしてください
<br>

## ルール説明<br>
- 盤面上にある鍵を取ってゴールする<br>
- プレイヤーは上下左右の4方向に進むことができ，開けられるマスはプレイヤーが行くことができるかつその周囲8マスである
<br>

## 操作説明<br>
**タイトル画面**<br>
- **1・2・3キー**：難易度（Easy/Normal/Hard）を選択してゲーム開始<br>
**ゲームプレイ**<br>
- **左クリック**：指定したマスへ移動する，またはマスを開ける<br>
- **右クリック**：旗を立てる・取り消す<br>
**リザルト画面**<br>
**C**キー：同じ難易度でリトライ<br>
**B**キー：タイトル画面に戻る<br>
**Esc**キー：ゲームをやめる
<br>

## 作品のコンセプトと面白さ<br>
私自身がマインスイーパーを好きでよく遊んでおり，これに迷路の探索という要素を加えたら，移動範囲に制限が生まれて面白さが生まれるのではないかというアイデアが制作の原点です．<br>
マスを開けたときに出る数字を頼りに地雷を避けながら，鍵を拾いゴールへ到達するゲームです．通常のマインスイーパーのすべてのマスを開けるとクリアというルールとは異なり，いかに少ない手数かつ地雷を避けて進めるかを評価するスコアシステムもあります．
<br>

## 本プロジェクトの制作目的<br>
本作品は，C++によるオブジェクト指向プログラミングの基礎力と，アルゴリズムやクラス設計の学習を目的に制作しました．<br>
単にゲームを完成させるだけでなく，将来的な機能追加に耐えうる拡張性の高い設計を意識して実装しています．
<br>

## 設計と機能説明

### 技術的なアピールポイント<br>
- **幅優先探索（BFS）の活用**<br>
スタートから鍵，鍵からゴールへの経路保証やプレイヤーの移動にBFSを使用しました．クリックしたマスに対し，まだ開いていないマスや地雷のマスを避けた最短経路を計算して移動する操作性を実現しました．<br>
- **キャラクターのアニメーションと視認性**<br>
経路の移動中には歩行，地雷を開けた場合にはダメージのアニメーションを追加してただ開けるだけの作業にならないように工夫しました．さらに，キャラクターがマスの数字に重なった際，キャラクター側を半透明にして数字を透過表示する処理を追加し，ユーザビリティを向上させました．<br>
- **オブジェクト指向設計と拡張性**<br>
各クラスの責務を明確に分離し，難易度の設定やギミック追加がしやすくなるようにし，拡張性を持たせました．今後の拡張性としてスコアを稼げるアイテムを追加することや壊せないブロックの導入が挙げられます．
<br>

### クラス説明
- **Titleクラス**<br>
タイトル画面の描画と入力処理を担当する．プレイヤーの選択に応じた難易度データを構築し，ゲームシーンへ受け渡す．
<br>
- **Gameクラス**<br>
ゲーム全体の心臓部であり，オブジェクトの初期化，入力処理，更新処理，描画を統括する．時間計測やスコア計算などゲーム全体の進行状態も管理する．
<br>
- **Cellクラス**<br>
各マスの状態（開閉，地雷の有無，旗，隣接地雷数）を保持し，描画の管理を行う．
<br>
- **Boardクラス**<br>
2次元配列によってマス目の状態を管理する．動的な盤面の生成，BFSによる経路探索，周囲の地雷数の計算など，盤面に関するロジックを提供する．
<br>
- **Playerクラス**<br>
キャラクターの座標やアニメーション，ダメージ処理を管理する．Gameクラスを介してBoardクラスから得た経路情報をもとに，移動処理を行う．
<br>
